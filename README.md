## Algoritma Tugas
1. Menyimpan data nilai mahasiswa dalam sebuah list.
2. Menghitung jumlah seluruh nilai.
3. Menghitung rata-rata nilai.
4. Menentukan nilai minimum dan maksimum.
5. Menghitung jumlah mahasiswa yang lulus dan belum lulus.
6. Menampilkan hasil pengolahan data secara teratur.
